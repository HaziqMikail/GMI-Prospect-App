# 🎓 GMI Prospect Application

## 📱 Overview
The **GMI Prospect Application** is an Android-based app developed to promote the **German-Malaysian Institute (GMI)** and its educational programs.  
It helps prospective students:
- Explore **Diploma**, **GAPP**, and **GUFP** courses.
- Check **eligibility** based on their academic results.
- Learn more about GMI through **About Us** and **Contact Us** sections.

If a student is found **eligible**, the app automatically redirects to the official **GMI Online Application Portal**:
👉 [https://gmi.vialing.com/oa/login](https://gmi.vialing.com/oa/login)

---

## ⚙️ Features
- 🧾 **Course List:** Displays all courses under Diploma, GAPP, and GUFP.
- ✅ **Eligibility Checker:** Evaluates student qualifications based on entered grades.
- 📨 **Enquiry Section:** Includes *About Us* and *Contact Us* pages for direct communication.
- 🔗 **Redirect Integration:** Opens the official GMI online application for eligible users.
